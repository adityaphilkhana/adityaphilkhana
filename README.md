### Venkata Rama Aditya Philkhana

Simulation engineer working on CFD, conjugate heat transfer and machine learning for thermal design. M.Sc. thesis on physics-informed graph neural networks for cold-plate cooling (Deggendorf Institute of Technology, carried out at RWTH Aachen University).

**Projects**

- **[AtomMesh](https://github.com/adityaphilkhana/atommesh-cht)**: automatic all-hex meshing for conjugate heat transfer. It takes STL input and writes a wall-resolved, two-region OpenFOAM case. Validated on 7 cold plates: every region passes checkMesh, and the interface heat error is at most 0.13 %. Against snappyHexMesh it meshes 6× faster and gives the same pressure drop.
- **[PIGNN for cold-plate CFD](https://github.com/adityaphilkhana/pignn-cold-plate-cht)**: a graph neural network surrogate that runs on unstructured CFD meshes. Physics-informed losses cut the pressure error by 92 % on unseen pin-fin geometries.
